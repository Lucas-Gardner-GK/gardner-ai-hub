01
Utgangspunktet

Normalt er AI
innestengt.

Claude, ChatGPT og andre AI-er lever på internett. De kan snakke med deg — men de kan ikke røre noe på datamaskinen din. De kan ikke lese filene dine, skrive til dem, eller gjøre noe på egen hånd.

Tenk på det sånn: AI er en ekstremt smart person som sitter bak et glassvindu. Du kan snakke med dem, men de kan ikke ta på noe i rommet ditt.
02
Hva er MCP?

MCP er
døren i glasset.

MCP — Model Context Protocol — er en protokoll laget av Anthropic (selskapet bak Claude) i 2024. Det er et felles språk som lar AI koble seg til verktøy, filer og systemer på utsiden.

Tolk-analogien: Tenk på MCP som en tolk. Claude snakker AI-språk. Mac-en snakker maskin-språk. MCP oversetter mellom dem slik at de kan jobbe sammen.
03
Min oppsett

Hva jeg faktisk
har bygget.

Jeg har koblet Claude Desktop direkte til hele filsystemet mitt via en MCP-server. Claude kan nå lese, skrive og opprette filer på Mac-en min.

// Konfigurasjonsfilen som kobler Claude til Mac-en:
// ~/Library/Application Support/Claude/claude_desktop_config.json

{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["@modelcontextprotocol/server-filesystem", "/Users/lucasgardner"]
    }
  }
}
04
Slik fungerer det

Steg for steg.

1. Jeg skriver til Claude
"Opprett en fil som heter test.txt og skriv Hei i den"
2. Claude forstår
Claude skjønner at dette krever tilgang til filsystemet
3. MCP oversetter
MCP-serveren sender kommandoen til Mac-en
4. Filen opprettes
test.txt dukker opp på Mac-en — uten at jeg rørte en knapp
05
I praksis

Hva Claude kan gjøre
på Mac-en min.

  • Lese alle filer og mapper under /Users/lucasgardner
  • Opprette nye filer og mapper
  • Skrive og redigere innhold i eksisterende filer
  • Søke etter filer på tvers av hele hjemmemappen
  • Oppdatere nettsiden min ved å endre kode direkte

07
Hvorfor dette er viktig

MCP er for AI
hva HTTP var
for internett.

HTTP var protokollen som lot alle nettsider snakke samme språk. Det skapte internett slik vi kjenner det. MCP gjør det samme for AI — det er standarden som lar AI koble seg til alle systemer.

Den infrastrukturen bygges akkurat nå. De fleste vet ikke at den finnes.
